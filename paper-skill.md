IEEE Formatting Rules
Two-column layout, 10 pt Times New Roman.

Margins and column widths per IEEE template.

Abstract: 150–250 words.

Index Terms: alphabetical, lowercase except proper nouns.

Section numbering: I, II, III, etc.

Figure and table captions: sentence case, placed below figures and above tables.

References: IEEE style, numbered in order of citation.

Page limits: follow venue-specific rules.

Equations: numbered consecutively, right-aligned numbers.

Writing Guidelines
Abstract: problem, method, key results, conclusion.

Introduction: motivation, problem statement, contributions, paper organization.

Related Work: compare and contrast, identify gap.

Methodology: reproducible, equations, pseudocode, parameters.

Results: baselines, metrics, statistical significance, error bars.

Discussion: interpret, limitations, threats to validity, future work.

Conclusion: summarize, impact, open problems.

Reference Management

Presentation (PPT) Creation
Purpose
Create effective presentation slides for IEEE conferences, seminars, and lectures based on the paper.

Core Competencies
Storyboarding: outline narrative, logical flow, key messages.

Slide design: layout, typography, color contrast, readability, minimal text.

Content extraction: distill paper into slides: title, motivation, problem, method, results, conclusion.

Visual aids: charts, diagrams, equations, screenshots, animations.

Data visualization: adapt figures for slides, simplify, highlight key trends.

Timing: slide count per minute, rehearsal, pacing.

Delivery: speaker notes, cues, transitions, Q&A preparation.

Tools: Microsoft PowerPoint, Google Slides, Apple Keynote, LaTeX Beamer, Canva, Prezi.

Accessibility: font size (≥24 pt), alt text, colorblind-safe palettes.

Backup: PDF export, offline copy, embedded fonts.

Workflow
Define audience and talk duration.

Outline slide structure: title, outline, motivation, problem, related work, method, results, discussion, conclusion, Q&A.

Create title slide: paper title, authors, affiliation, conference.

Design consistent template: colors, fonts, logo.

Develop content slides: one idea per slide, 6x6 rule (max 6 bullets, 6 words per bullet).

Add visuals: figures, tables, equations, diagrams.

Write speaker notes.

Rehearse and time.

Export to PDF and backup formats.

Prepare for Q&A.

Slide Structure Template
Title slide: title, authors, affiliations, date, conference.

Outline slide.

Motivation: why this problem matters.

Problem statement: formal definition.

Related work: brief comparison, gap.

Proposed method: overview diagram, key equations.

Implementation: setup, parameters, dataset.

Results: main table or graph, baselines, improvement.

Discussion: interpretation, limitations.

Conclusion: summary, future work.

Acknowledgment.

Q&A / Thank you.

Backup slides: extra details, proofs, additional results.

Slide Design Guidelines
Font: sans-serif (Arial, Calibri, Helvetica), min 24 pt.

Colors: high contrast, limit to 3–4 colors, use colorblind-safe palettes.

Background: plain, light, or dark with consistent contrast.

Text: minimal, bullet points, no full sentences.

Figures: large, clear, labeled, vector when possible.

Equations: simplified, large, step-by-step if needed.

Animations: subtle, only to reveal steps, avoid distractions.

Transitions: simple, consistent.

Footer: slide number, conference name, author.
